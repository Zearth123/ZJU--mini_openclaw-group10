# 活动策划基本原则

## 一、需求分析原则

### 1.1 明确活动本质

每项活动需首先明确：
- **为什么办** — 活动目的（交流/培训/展示/招募/庆祝）
- **给谁办** — 目标人群画像
- **什么算成功** — 可衡量的成功指标

### 1.2 约束优先级

当目标与约束冲突时，按以下优先级取舍：

```
安全 > 体验 > 预算 > 形式
```

即：安全红线不能碰 → 参与者体验优先 → 预算可调整 → 活动形式可灵活变化

### 1.3 缺失信息处理

信息缺失时按以下顺序处理：
1. **询问用户** — 最推荐
2. **合理假设** — 需在方案中标注
3. **参考历史** — 从类似活动中借鉴

---

## 二、方案设计原则

### 2.1 活动结构

好的活动流程应包含：

```
开场（10-15%）→ 主体（60-70%）→ 收尾（10-15%）→ 撤场（5-10%）
```

- **开场**：签到、破冰、介绍流程
- **主体**：核心环节（讲座/创作/比赛/互动）
- **收尾**：总结、合影、反馈收集
- **撤场**：物资整理、场地清理

### 2.2 时间分配

- 每个环节至少预留 5 分钟缓冲
- 环节切换时间计入总时长
- 布置时间建议提前 30 分钟
- 撤场时间建议 15-30 分钟

### 2.3 参与体验

- 避免纯听讲超过 45 分钟
- 穿插互动环节保持参与度
- 考虑不同参与者的需求差异
- 预留自由交流时间

---

## 三、预算原则

### 3.1 预算结构

```
总预算 = 物资材料 + 宣传 + 餐饮 + 设备 + 装饰 + 奖品 + 交通 + 应急备用金
```

应急备用金 = 总预算 × 10%（不少于 10%）

### 3.2 削减优先级

超预算时按以下顺序削减（从最先到最末）：
1. 装饰品、纪念品
2. 餐饮标准
3. 奖品金额
4. 物资数量
5. 寻找免费替代方案
6. 调整活动形式降低成本

### 3.3 费用记录

- 每笔支出必须记录对应凭证
- 预算偏差超过 20% 需要说明原因
- 备用金使用需审批

---

## 四、分工原则

### 4.1 任务拆分

每个大任务应拆解为：
- 可独立执行的最小任务单元
- 每个单元指定唯一负责人
- 明确截止时间
- 定义完成标准

### 4.2 工作量均衡

- 核心成员承担任务不超过 3 项
- 普通成员承担任务不超过 2 项
- 避免一人多岗导致注意力分散
- 关键岗位需指定替补

### 4.3 沟通机制

- 建立活动筹备群
- 会前 3 天、1 天分别确认进度
- 活动当天提前 30 分钟到场确认

---

## 五、宣传原则

### 5.1 宣传时间线

| 时间节点 | 动作 |
|----------|------|
| 活动前 7-10 天 | 发布活动预告 |
| 活动前 3-5 天 | 发布正式报名推文 |
| 活动前 1-2 天 | 报名截止 + 确认通知 |
| 活动当天 | 现场签到 |
| 活动后 1-2 天 | 活动回顾推文 |

### 5.2 多渠道覆盖

- 公众号推文
- 微信群通知
- 海报张贴
- 口头宣传

---

## 六、风险管理原则

### 6.1 风险分级

| 等级 | 判断标准 | 处理要求 |
|------|----------|----------|
| 高 | 极可能发生且影响严重 | 必须制定专项预案 |
| 中 | 可能发生或有一定影响 | 准备应急方案 |
| 低 | 不太可能或影响轻微 | 知晓即可 |

### 6.2 风险应对策略

- **规避**：调整方案消除风险
- **转移**：保险或外包
- **减轻**：降低发生概率或影响
- **接受**：准备应急预案

---

## 七、活动状态管理

活动应按照生命周期管理：

```
DRAFT → PLANNING → APPROVED → PREPARING → IN_PROGRESS → COMPLETED → REVIEWED
```

| 状态 | 可执行操作 |
|------|-----------|
| DRAFT | 修改活动目标 |
| PLANNING | 生成预算、分工、时间表 |
| APPROVED | 锁定主要方案 |
| PREPARING | 更新任务完成情况 |
| IN_PROGRESS | 记录现场问题 |
| COMPLETED | 录入实际支出和参与人数 |
| REVIEWED | 生成并保存复盘报告 |
