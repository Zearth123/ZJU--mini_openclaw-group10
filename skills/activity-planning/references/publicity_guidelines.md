# 宣传写作指南

## 一、活动名称命名规范

### 命名公式

```
【品牌词】+ 核心词 + 亮点词
```

例：
- 「春日墨韵·书画体验交流会」
- 「计协 x 谷歌：AI 编程工作坊」

### 命名原则

- 控制在 8-15 字
- 体现活动类型和核心内容
- 有画面感或行动号召
- 避免过于抽象或晦涩

---

## 二、推文结构

### 招募推文结构

```
标题：吸引眼球 + 明确信息

1. 开头段（100-150 字）
   - 活动一句话介绍
   - 为什么值得参与
   - 目标人群

2. 活动详情（200-300 字）
   - 活动内容
   - 活动流程
   - 活动亮点

3. 关键信息（清晰醒目）
   - 时间：x月x日 xx:xx-xx:xx
   - 地点：xxx
   - 人数：xx 人
   - 费用：免费/xx 元

4. 报名方式
   - 二维码/链接
   - 截止时间
   - 联系人及联系方式

5. 往期回顾（如有）
   - 1-2 张活动照片
   - 参与者评价
```

### 活动回顾推文

```
标题：活动回顾 + 成果/亮点

1. 开场（概述活动成果）
2. 活动过程回顾（图文并茂）
3. 参与者感言（引用 1-2 条）
4. 成果展示（照片/作品）
5. 感谢语 + 下次活动预告
```

---

## 三、渠道语言风格

| 渠道 | 风格 | 字数 | 特点 |
|------|------|------|------|
| 公众号推文 | 正式、完整 | 800-1500 字 | 图文并茂，信息完整 |
| 微信群通知 | 亲切、简洁 | 100-200 字 | 突出时间和报名方式 |
| 海报文案 | 简洁、醒目 | 20-50 字 | 突出亮点和关键信息 |
| 口头宣传 | 口语化 | 30-60 秒 | 引起兴趣，引导报名 |

---

## 四、文案长度限制

| 用途 | 建议长度 |
|------|----------|
| 公众号标题 | 15-25 字 |
| 海报主标题 | 8-12 字 |
| 群通知 | 100-200 字 |
| 报名确认 | 50-100 字 |
| 活动提醒 | 30-50 字 |

---

## 五、内容红线

- ❌ 不得使用"最""第一""唯一"等绝对化用语
- ❌ 不得虚假承诺活动效果（如"保证学会"）
- ❌ 不得泄露参与者个人信息
- ❌ 不得使用未经授权的图片或字体
- ❌ 不得夸大参与人数或活动规模
- ✅ 必须包含活动时间和地点
- ✅ 必须说明报名方式和截止时间
- ✅ 必须提供联系人信息

---

## 六、亮点提炼方法

从以下角度提炼活动亮点：

1. **稀缺性**：名额有限、大师指导、首次举办
2. **成果感**：带走作品、获得证书、学到技能
3. **社交价值**：认识同好、拓展人脉
4. **体验感**：互动环节、沉浸体验
5. **实惠性**：免费参与、提供材料、有奖品
